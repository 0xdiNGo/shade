# Shade

Modern IRC bot and channel-management mesh, written in Rust.

Successor to Wraith. Same bot family — encrypted node-to-node mesh, distributed channel-protection roles, hardened cookie-op verification — but rebuilt for container-forward deployment, declarative configuration, and modern observability. Not interoperable with Wraith botnets.

## Status

Pre-alpha. Not yet usable. Not for production.
